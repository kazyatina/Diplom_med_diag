# Проект Сайт для медицинского диагностического центра
## Описание
Сайт для компании медицинской диагностики. Сайт сверстан и подключен к админке. 
Использованы Django и Bootstrap. Сайт содержит основные разделы, необходимые 
для функционирования медицинской диагностической компании.
___
## Активация django в виртуальном окружении
- python -m venv .venv - Создайте виртуальное окружение
- venv\Scripts\activate (Windows) - Активируйте виртуальное окружение
- для poetry: poetry add django далее poetry export -f requirements.txt --output requirements.txt
- для venv: pip install django далее pip freeze > requirements.txt

## Работа с django
- django-admin startproject config . - инициализирует проект в корневой директории
- вариант 2 - django-admin startproject <название_проекта> - инициализирует проект в отдельной директории
- python manage.py startapp <название_приложения> - создает директорию с приложением запускает работу приложения
- pip install psycopg2-binary - установка библиотеки для работы с базами данных Postgres
- pip freeze > requirements.txt - обновление файла с зависимостями
- pip install python-dotenv - установка библиотеки для работы с защитой секретных данных
- pip freeze > requirements.txt - обновление файла с зависимостями
- pip install Pillow - установка библиотеки для работы с изображениями
- python manage.py makemigrations app_name - создает миграцию, которая зафиксирует эти изменения.
- python manage.py migrate - применяет миграцию к базе данных
- - python manage.py migrate app_name migration_name - откатить миграцию до конкретной версии, указав имя приложения и номер миграции
- - python manage.py migrate app_name zero - откатить все миграции и вернуть базу данных в состояние, когда ни одна миграция не была применена
- python manage.py createsuperuser - Для создания суперпользователя
- pip install ipython - установите пакет ipython, Чтобы Django shell был удобным в использовании
- poetry add ipython - для poetry
- python manage.py shell -i ipython - запустите Django shell с IPython
- Для выхода из Django Shell используйте команды exit(), quit() или сочетание клавиш Ctrl + D или Ctrl + Z
- python -Xutf8 manage.py dumpdata [приложение].[модель] --output [файл.json] --indent 4 - Базовая команда для экспорта данных модели в файл
- python manage.py loaddata файл.json --format json - Загрузка данных с указанием формата файла на Windows
- python manage.py команда - Вызов кастомной команды
- - python manage.py runserver - запуск сервера

## Приложения
- accounts - зарегистрированные клиенты центра
- appointments - записи на прием к врачам
- core - услуги центра и команда врачей

## Создание и настройка приложения `core`:

*   Создано новое Django-приложение под названием `core` с помощью команды `python manage.py startapp core`.
*   Приложение `core` зарегистрировано в настройках проекта (в `INSTALLED_APPS` в файле `BASE_DIR/settings.py`). 
В список `INSTALLED_APPS` добавлена строка `'core'`, указывающая на регистрацию приложения.
*   Настроена маршрутизация для приложения:
    *   Создан файл `urls.py` в директории приложения `core`.
    *   В главном файле `BASE_DIR/urls.py` проекта добавлено подключение маршрутов приложения `core` с использованием функции `path` и `include`.

**Реализация контроллеров (Views):**

*   В файле `views.py` приложения `core` созданы контроллеры:
    *   Контроллер для отображения домашней страницы (`home`). 
    Этот контроллер возвращает отрендеренный шаблон `home.html` с помощью функции `render`.
    *   Контроллер для отображения страницы с информацией о центре (`about`). 
    Этот контроллер возвращает отрендеренный шаблон `about.html` с помощью функции `render`.
    *   Контроллер для отображения списка услуг (`services`). 
    Этот контроллер возвращает отрендеренный шаблон `services.html` с помощью функции `render`.
    *   Контроллер для отображения страницы с контактной информацией (`contacts`). 
    Этот контроллер возвращает отрендеренный шаблон `contacts.html` с помощью функции `render`.
    
**Настройка маршрутизации для контроллеров:**

*   В файле `urls.py` приложения `core` настроена маршрутизация для контроллеров с использованием функции `path`:
    *   Определен URL-путь для домашней страницы (например, пустая строка `''`, `'home/'`, `'/'`), который связан с контроллером `home`.
    *   Определен URL-путь для отображения страницы с информацией о центре (например, `'about/'`), который связан с контроллером `about`.
    *   Определен URL-путь для отображения списка услуг (например, `'services/'`), который связан с контроллером `services`.
    *   Определен URL-путь для страницы контактов (например, `'contacts/'`), который связан с контроллером `contacts`.

    *   Определен URL-путь для отмены записи на прием (например, `'<int:appointment_id>/cancel/'`), который связан с контроллером `cancel_appointment`.

*   Создана директория `templates` внутри корневой директории приложения `meddiag`.

    *   `services.html` - шаблон для страницы списка услуг.

    Подключение Bootstrap CSS и JavaScript, выполнено через CDN в шаблонах.

**Запуск проекта и доступ к страницам:**

*   Для запуска проекта необходимо перейти в терминал и выполнить команду `python manage.py runserver`.
*   Доступ к домашней странице осуществляется по адресу `http://127.0.0.1:8000/` (или другому адресу, указанному в выводе команды `runserver`).
*   Доступ к странице контактов осуществляется по адресу `http://127.0.0.1:8000/contacts/`.

# Запуск проекта с использованием Docker Compose
Файл docker-compose.yml определяет конфигурацию для запуска всех необходимых сервисов вашего проекта: 
веб-приложения Django, базы данных PostgreSQL.

## Предварительные требования
- Docker установлен и работает.
- Docker Compose установлен (обычно входит в состав Docker Desktop).
- Файл .env с необходимыми переменными окружения (например, DATABASE_NAME, DATABASE_USER, DATABASE_PASSWORD). 

### Процесс запуска
1. Сборка и запуск всех сервисов.
Перейдите в корневую директорию вашего проекта (где находится файл docker-compose.yml и Dockerfile). 
2. Затем выполните следующую команду:
docker-compose up --build или docker-compose -f docker-compose.yml up

### Полезные команды

Сбилдить образы без запуска: docker-compose build

Запустить контейнеры в фоне (демоне): docker-compose up -d

Просмотр логов: docker-compose logs -f

Подключиться в терминал работающего контейнера, например web: docker exec -it online-education bash
